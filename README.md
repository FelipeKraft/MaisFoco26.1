# +FOCO 🎯

Aplicativo de produtividade com técnica Pomodoro e sistema de recompensas. Criado por:

Felipe Mitraud Kraft, 
Enzo Carvalho Martins, 

## ✨ Funcionalidades

- ⏱️ Timers Pomodoro (25/5 min e 50/10 min)
- 🎁 Sistema de recompensas personalizáveis
- 💰 Sistema de pontos por minuto trabalhado
- 📊 Informações sobre saúde digital

## 🚀 Como usar

1. Escolha um timer Pomodoro
2. Ganhe 1 ponto a cada minuto de trabalho
3. Cadastre suas recompensas
4. Resgate suas recompensas com os pontos ganhos
